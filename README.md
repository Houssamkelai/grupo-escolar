# Grupo Escolar España / Collège Imam Malik — Modélisation 3D

Projet de reconstruction architecturale 3D du **Grupo Escolar España**, actuel **Collège Imam Malik**, situé à Larache, au Maroc.

Ce projet vise à documenter, reconstruire et valoriser numériquement ce bâtiment historique à partir de photographies, relevés de terrain, vues satellite, croquis, mesures et témoignages directs.

---

## Objectif du projet

L’objectif principal est de produire un modèle 3D fidèle du bâtiment afin de permettre :

- l’étude de son architecture ;
- la conservation numérique de son état actuel ;
- la production de rendus réalistes ;
- la création d’une visite virtuelle interactive ;
- l’intégration du modèle sur le web ;
- l’utilisation du modèle dans des projets patrimoniaux et pédagogiques ;
- une éventuelle préparation future pour l’impression 3D.

Le modèle ne cherche pas à proposer une interprétation libre du bâtiment, mais une reconstruction fondée sur les documents disponibles.

---

## Bâtiment

**Nom historique :** Grupo Escolar España  
**Nom actuel :** Collège Imam Malik  
**Ville :** Larache  
**Pays :** Maroc

Le complexe s’organise autour d’une grande cour principale et comprend notamment :

- un corps nord donnant sur l’Avenue Moulay Ismail ;
- une aile Est ;
- une aile Ouest ;
- un pavillon central ;
- plusieurs volumes bas ;
- des murs de clôture ;
- des façades intérieures donnant sur la cour ;
- des éléments architecturaux d’inspiration hispano-mauresque.

---

## Sources utilisées

La reconstruction repose sur plusieurs types de sources :

- photographies actuelles des façades ;
- photographies prises depuis la cour ;
- photographies de détails architecturaux ;
- vidéos de parcours intérieur ;
- vues satellite ;
- mesures effectuées sur Google Maps ;
- croquis manuels ;
- dessins d’élévation ;
- relevés visuels ;
- témoignages directs liés à l’histoire et aux transformations du bâtiment.

Les sources photographiques et les mesures réelles sont prioritaires lorsqu’elles contredisent un dessin ou une interprétation précédente.

---

## Méthode de reconstruction

La modélisation a été réalisée progressivement.

### 1. Analyse documentaire

Les documents ont d’abord été classés et comparés afin de comprendre :

- la géométrie générale du bâtiment ;
- la forme de la parcelle ;
- l’orientation des ailes ;
- la position du pavillon central ;
- la disposition des ouvertures ;
- les différentes familles de fenêtres ;
- les volumes de toiture ;
- les parties certaines et les parties encore hypothétiques.

### 2. Blockout

Un premier modèle volumétrique a ensuite été construit afin de vérifier :

- les proportions générales ;
- les longueurs principales ;
- les relations entre les volumes ;
- la forme en U ;
- la position de la cour ;
- l’implantation du pavillon central.

### 3. Modélisation détaillée

Après validation du blockout, les détails architecturaux ont été ajoutés :

- fenêtres ;
- portes ;
- arcs ;
- corniches ;
- parapets ;
- créneaux ;
- pilastres ;
- grilles métalliques ;
- toitures ;
- tuiles ;
- soubassements ;
- détails des façades.
